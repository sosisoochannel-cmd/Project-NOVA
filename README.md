# PROJECT FOOTBALL

A clean, independent Unity 6 football-game project targeting Android.

## Engine
- Unity: **6000.3.24f1**
- Render pipeline: Built-in (kept lightweight for the first Android foundation)
- Target: Android / ARM64
- Match target: 11 vs 11

## Current foundation
- Runtime-generated football pitch and goals
- 22 placeholder player bodies in a basic formation
- Rigidbody-based ball and kick interaction
- Basic selected-player movement
- Broadcast-style follow camera
- Goal detection and scoreboard
- GitHub Actions Android build workflow

> This is an early playable foundation, not an FC/eFootball-quality finished game. Placeholder capsules are deliberately temporary. Real player models, licensed assets, advanced animation, tactical AI, passing, goalkeeper logic, stadium art and full mobile controls are planned in later phases.

## Open in Unity
1. Use Unity Hub with **Unity 6000.3.24f1** and Android Build Support (SDK, NDK, OpenJDK).
2. Clone this repository.
3. Open the repository root as a Unity project.
4. Open **Assets/ProjectFootball/Scenes/Bootstrap.unity** and press Play.
5. For Android, switch platform to Android, set ARM64, then build.

The scene and all match objects are generated by the included runtime bootstrap.

## Android cloud build
The workflow at `.github/workflows/android-build.yml` can build an APK in GitHub Actions. Configure repository Actions secrets:
- `UNITY_LICENSE`
- `UNITY_EMAIL`
- `UNITY_PASSWORD`

Then run **Actions → Unity Android Build → Run workflow**. A valid Unity license is required. The workflow uploads the APK as an artifact.

## Phone-first workflow
Project files can be edited and managed from GitHub's mobile website. Unity Editor itself does not run natively on a typical Android phone; actual Unity import/play-mode verification and local editor work require a supported computer. Cloud CI can compile/build after Unity licensing is configured.
